# 0-target: LendingPool

Lends ETH against the bridged token at a governance-set price. It assumes every token in circulation is backed by ETH locked on the source chain. Correct on its own.

On Ethereum: the Aave V3 [Pool](https://etherscan.io/address/0x87870Bca3F3fD6335C3F4ce8392D69350B4fA4E2), where the released rsETH was posted as collateral.
