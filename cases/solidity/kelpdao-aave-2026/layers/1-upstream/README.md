# 1-upstream: BridgedRestakeToken

Mints tokens when the endpoint delivers a "locked on the source chain" message. It assumes every delivered message is genuine. Correct on its own.

On Ethereum: the [rsETH token](https://etherscan.io/address/0xa1290d69c65a6fe4df752f95823fae25cb99e5a7) and KelpDAO's [RSETH_OFTAdapter](https://etherscan.io/address/0x85d456b2dff1fd8245387c0bfb64dfb700e98ef3), which released 116,500 rsETH in [this transaction](https://etherscan.io/tx/0x1ae232da212c45f35c1525f851e4c41d529bf18af862d9ce9fd40bf709db4222#eventlog).
